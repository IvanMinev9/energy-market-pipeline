# Energy Market Data Pipeline

## Overview

Energy Market Data Pipeline is a data engineering project designed to collect, transform and store energy market related data.

The goal of the project is to build a complete ETL pipeline using Python, APIs, PostgreSQL and modern data engineering practices.

## Architecture

|

|

↓

|
